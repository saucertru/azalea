ROMS (EmulatorJS)
Drop ROM files here. The system is picked from the file extension:
  .nes .sfc/.smc .gba .gb/.gbc .n64/.z64 .nds .md/.gen .sms .gg .a26 .pce ...
For .zip or .bin files, put them in a folder named after the system:
  games/roms/gba/game.zip   games/roms/psx/game.bin   games/roms/arcade/game.zip
Same-name image = cover (game.gba + game.png).
Only add ROMs you legally own or that are homebrew / public domain.
